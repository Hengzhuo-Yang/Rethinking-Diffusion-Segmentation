# Upstream identification

## Project and paper

- Project: **MedSegDiff: Medical Image Segmentation with Diffusion Model**
- Paper: Junde Wu et al., “MedSegDiff: Medical Image Segmentation with Diffusion Probabilistic Model,” MIDL 2023, arXiv:2211.00611.
- Official repository: <https://github.com/ImprintLab/MedSegDiff>
- Local upstream remote: `https://github.com/ImprintLab/MedSegDiff.git`

## Baseline revision

The local Git repository is based on commit
`28b343fddd6bb6dc1bccdaed94ca7ebefe9142f3` (`Update README.md`,
2025-09-10). The local `master` branch and `origin/master` pointed to that
revision when this release directory was prepared.

The runnable research tree also contained substantive tracked modifications and
untracked dataset/audit support. Those working-tree files, rather than a clean
checkout of the baseline commit, are the functional source of this release.
Formal experiment logs correlate this tree with the commands and audit metadata,
but the historical cloud source archive was unavailable and the logs did not
record a source hash. Byte-for-byte identity with that cloud copy therefore
cannot be asserted.

The unmodified upstream README is retained at `code/README.md`. It is historical
upstream documentation; the release commands and environment are documented in
the repository-root README.
